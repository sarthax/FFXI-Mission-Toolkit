# reports/

Audit/status reports for your backport project — either hand-written, or generated by the packaged
validation CLIs this workspace defaults `backport_root` for:

- `py -3 -m workbench.validation.packages.binding_audit --all-packages`
- `py -3 -m workbench.validation.packages.lua_sanity --all-packages`

Ships empty on purpose; this is where your own project's real findings accumulate over time.
