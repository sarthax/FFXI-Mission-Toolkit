### #1322 mapping, not duplicated

PR #1322, when independently reviewed and owner-authorized for merge, adds
`GET /feature-testing/r8/catalog` and
`GET /feature-testing/r8/preflight/{feature_id}/{case_id}`.
Those are **JSON-only**, canonical-v1/optional-v2 based, read-only *advisory*
operations. They show MOG-09's fixed local-operator runner, design-only
INV-OBS-01, planning-only Gardening/other staged cases and explicit
UNKNOWN/BLOCKED requirements, but do **not** implement a user-facing landing
page, solve the Validation DB setup, or supply a general runner, approved
oracle, deployed source attestation, or task admission. This independent
navigation PR deliberately avoids linking to unmerged R8 URLs.

### User-visible limitations and follow-ups

- Missing `workbench.db` or absent canonical run records remains explicit; all
  five navigation cards render regardless of that error. No new DB is created.
- A "Ready" declaration elsewhere in the existing Build & Run environment is
  **not** permission for agent execution. #1333's production/sandbox config
  inheritance is P0/P1 and needs independent fail-closed configuration work.
- The Scenario Developer's unsaved new/fork leave-page guard and field-specific
  validation errors are assigned separately (#1333/#1323), not solved by links.
  This page explicitly warns operators about unsaved navigation loss.
- Evidence Reviewer is standalone and generated by an operator from an
  indexed capture database; physical capture bytes are not authenticated by
  rendered/indexed metadata. Its JSON exports are noncanonical and must not
  auto-import into the scenario spec or become an approved oracle.
- MOG-09's runner remains a separately constrained **local operator** path.
  INV-OBS-01 has no runner; 73 staged design cases are NOT_RUN. The proposed
  R8 preflight always retains `execution_status=NOT_AUTHORIZED` and
  `execution_enabled=false`; readiness cannot be derived from static
  source/provider claims alone.
- B20 browser capture attachment acceptance, isolated Windows configuration,
  responsive/keyboard QA and real local flows remain **NOT TESTED** by this PR.
