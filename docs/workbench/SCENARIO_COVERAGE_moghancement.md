| MOG-02 | Same-element strongest installed furnishing determines KI | `needs-mutation` | Complete per-slot installed state and source-verified items missing |

| MOG-05 | Replacing prior KI removes stale KI and modifiers | `needs-mutation` | Independent full held KI + modifier readback missing |
| MOG-06 | Uninstall and relog persistence | `needs-mutation` | Reliable client uninstall, server save-boundary and reconnect evidence missing |
| MOG-07 | GM info aura breakdown matches independent source oracle | `needs-mutation` | No independent installed furniture manifest; GM diagnostic is same-server-derived evidence |
| MOG-08 | Elemental tie clears KI | `needs-mutation` | Need two-Safe installed manifest, typed compare and held KI readback |
| MOG-09 | Stored but uninstalled furnishing grants none | `observe-now` | Canonical observed PASS is imported/limited; installed layout not independently observed |
| MOG-10 | Empty layout clears KI | `needs-mutation` | Need full both-Safe installed flag readback and cleanup |
| MOG-11 | Repeated recompute does not stack effects | `needs-mutation` | Independent per-modifier readback, exact baseline of other modifiers and permission |
| MOG-12 | Invalid forced KI rejected | `needs-mutation` | Mutation is GM and forbidden in this assignment; accepted invalid value partition/fixture and readback missing |
| MOG-13 | Duplicate furnishings change aura but not KI count | `needs-mutation` | Need complete container/slot identity, installed flags, held KI list and modifiers |
| MOG-14 | Equal strongest furnishings follow DSP scan order | `needs-mutation` | Full per-container ordered placement and C++ deployed source revision unverified |

Only **MOG-09's existing limited observation contract** qualifies for `observe-now`; no new test run was performed. MOG-07's GM info snapshot can be captured read-only on an authorized profile, but full layout-to-aura verification is `needs-readback`, not a verified full PASS. Thirteen complete new mutations remain `needs-mutation` (MOG-07 independently reading a persisted profile may skip mutation if the fixture already exists). Deployed server revision is UNKNOWN and must be checked.
