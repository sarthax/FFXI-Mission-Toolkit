## Contract v2 compatibility audit — proposal #1285 (not adopted)

- `test_specifications.py` canonical v1 requires `schema_version=1`, allowlisted operations, observations and runners, and strict step fields `id,title,intent,expected,assertion_ids,evidence_refs`. Staged records contain novel operations/readback types, `action` and different citation field names; **no direct import**.
- Proposal `contract_v2` is *optional metadata* inside canonical v1, not a standalone replacement. `sources[]` requires `ref,repository,path,line_start,line_end,revision,classification,sha256`. Existing staged `commit` must map to `revision`; **source content SHA-256 digests are absent**, cannot be substituted with Git blob SHA or guessed. Unknown digest must remain null/UNKNOWN pending independent attestation.
- `parameters[]` accepts only typed bounded catalog identities with binding states `unresolved`, `candidate`, `ambiguous`, `independently_source_verified`; NPC/mob verification needs zone scope and independent source digest. A named mob, NPC script comment or dynamic spawn is not by itself verified identity.
- `oracles[]` must reference existing v1 assertion IDs; design UNKNOWN requires `oracle_type=unknown`, `confidence=unknown`, no source refs. A source predicate can be marked source-cited only with a properly pinned digest, *not* automatically as a verified expected outcome.
- `step_requirements[]` requires step ID, operation class, permissions, readbacks, operator approval and **`execution_gate=blocked`**. Legacy `xiheadless` strings and Toolkit packet/GM names are *capability candidates*, not validated action registrations.
- `fingerprints` require a canonical v1 base-spec SHA-256 and optional DSP/headless/Toolkit SHAs. Staging artifacts **are not canonical v1 spec objects** and cannot have a meaningful canonical base-spec digest without an explicit deterministic mapper and human-approved v1 assertions. Local draft store still has a 32KiB size cap; do not copy entire domain JSON into one draft.
- Agent C (#1259/#1285) owns schema field mapping and rejection cases; Agent A owns integration/reconciliation. No adapter/runnable-catalog changes made here.
