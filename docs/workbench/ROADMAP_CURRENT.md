## Working and review rules

One owner-directed slice (or tightly coherent batch), one focused PR, actual offline validation and specific acceptance; no coordinator-agent claim/dispatch ritual. Check existing PRs first, including documentation overlap with [draft #1314](https://github.com/sarthax/FFXI-Mission-Toolkit/pull/1314). Do not copy its stale roadmap replacement over this short current page; reconcile unique operator CI/release guide corrections independently.

An **open/draft** PR is not merged functionality. Synthetic byte-identity checks and CI on previous commits are not executable-test, gameplay or usability PASS. Protect credentials, user identity, raw captures, DB and local test characters; live authorization is explicit and operator-owned. Use local-first testing, avoid repeated hosted Actions on drafts, and record exact-head results before owner merge approval.

**PR #1450 merge caution:** this retirement branch was created before many subsequent main commits. Rebase/reconcile its `AGENTS.md` and archived-roadmap changes against latest `main`; retain the newest Scenario Developer evidence history in the archive. Do **not** merge the stale branch automatically.
