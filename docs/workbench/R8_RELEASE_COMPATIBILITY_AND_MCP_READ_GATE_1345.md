## 2. Explicit compatibility verdict

**ACCEPT: #1322 and #1334 source-level compatibility; CONDITIONAL release, NOT owner permission.** The six and four changed paths are disjoint. #1322 adds pure `r8_catalog_preflight.py` and two GET-only Feature Testing endpoints; #1334 changes the existing `/validation` template plus offline tests/docs/workflow. No competing `workbench.db`, invented hosted Evidence Reviewer, duplicate canonical catalog or changed `/validation/runs`/Feature Testing URLs. The existing `/feature-testing/preflight/{feature_id}/{case_id}` is **environment-aware, legacy operator preflight**; `/feature-testing/r8/preflight/{feature_id}/{case_id}` is **pure metadata advisory**. #1334's copy correctly distinguishes them and is release-order neutral.

**ACCEPT: canonical v1/optional-v2 semantics, limited to source declarations.** #1322's stable identity is the *published canonical specification* `(feature_id,case_id)`; its **response field** is `scenario_id` mapped from that exact `case_id`, not a new identity namespace. Outer `schema_version=1`, optional `contract_v2.contract_version=2`; CASE/STEP source attribution only for explicitly declared scoped refs. `local_definition_sha256` is local sorted/compact ASCII JSON serialization, **not** a signed file/source-byte/deployed revision or a saved draft revision. MOG-09 has a **fixed local-operator observation runner** subject to its pre-existing restrictions. INV-OBS-01 is `UNASSIGNED_DESIGN_ONLY`; feature planning links, Gardening and 73 staged domain cases are **not registered as executable**. No generic XIHeadless dispatch or additional authority.

**ACCEPT: #1330 *design-envelope* translation with strict separate authority.** Its `toolkit-r8-scenario-discovery/1` `status=OK|UNKNOWN|BLOCKED|UNSUPPORTED` diagnoses bounded metadata, **not** gameplay state; #1322 *preflight* `checks[].state=DECLARED|UNKNOWN|BLOCKED` and aggregate `preflight_state=UNKNOWN|BLOCKED` must remain unchanged. An explicitly unsupported provider can be reported as a separate `UNSUPPORTED` discovery diagnostic but required observation satisfaction still fails closed; no new `READY` or executable state. Field adapters are projections of existing validated objects, not a second canonical spec model.

**REJECT as unproven / do not integrate:** `SOURCE_INTEGRATED` ⇒ deployed, persisted DB status ⇒ client agreement, a string-matched observation name ⇒ a provider capability, a matching preview digest ⇒ saved revision/signed source, a candidate oracle ⇒ approved expected result, an imported PASS ⇒ independently verified gameplay, a shared attempt ID ⇒ run/operation identity, and the catalog GET ⇒ an authenticated MCP tool. No installed supervisor scenarios endpoints, live execution or proposal-writing interface is approved by this finding.
