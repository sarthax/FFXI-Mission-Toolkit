## Semantics
`action` = a declarative command candidate, not an issued RPC; `expectation` = validation of asserted field shape, not an independent oracle; `observation` = actual readback/capture with provenance and completeness; `verdict` = **normative conclusion only after approved independent evidence and source/attempt identity**. Raw packet opcodes and capture events, even when recorded, are neither safe replay nor state readback. No packet emitter, GM command, mutation, supervised task admission, consumer wiring, browser, database or gameplay is implemented here.

## Tier contract and mandatory negative examples
`HEADLESS_SCHEMA_ONLY`: key and parameter/expectation shapes verified at pinned HEAD; dispatch/result/evidence authority UNKNOWN. `TOOLKIT_READBACK_ONLY`: actual Toolkit readback route documented but local authorization, deployment/source fingerprint, completeness and client comparison NOT_RUN. `UNSUPPORTED` should be used for any key not present in pinned schema, missing permission, unverified entity IDs, unknown oracle, missing artifacts, server mismatch or packet-only claims; never default to supported. An unsupported fake `warp_to`, a malformed `walk_to` coordinate, unauthorized test charid, missing pagination page, unknown Headless source revision, or reported PASS without independent readback must yield **BLOCKED/UNKNOWN**, not an actionable step or oracle. Do not map unsupported `NONE` to a callable action.
