Choose a validation workflow

These tools have different data sources and approval requirements. A published scenario, saved design, indexed capture, or recorded verdict does not by itself establish independently verified gameplay.

Scenario Catalog

Browse feature-testing cases and their recorded design status. Published specifications and planning-only domain cases are not interchangeable.

Browse scenario catalog The R8 canonical catalog API is a separate release candidate (#1322), not an installed gateway on this main revision.

Scenario Developer

Create, reopen and validate design-only drafts in the existing editor. Saving a draft does not publish it as runnable or approve its expectations.

Open Scenario Developer Review unsaved changes before leaving the editor; a full unsaved-work navigation guard is tracked separately in #1333.

Scenario Preflight

Inspect a published case and its prerequisites before considering any local operator action. Missing observers, source revisions, approved oracles and permissions can leave requirements UNKNOWN, BLOCKED or UNSUPPORTED.

MOG-09 scenario detail Current MOG-09 preflight JSON The existing preflight may inspect configured local prerequisites. It is not the separate R8 pure advisory preview, and neither page authorizes execution.

Evidence Reviewer (offline)

Review an indexed capture as a standalone local HTML report. The reviewer is not a hosted Toolkit page and cannot attest original capture bytes or authorize an oracle.

Find indexed captures Operator-generated report: python -m workbench.captures.scenario_review_offline --database <capture-index.sqlite> --capture-id <id> --output <review.html>. The in-app Capture Review Queue is a different workflow.

Results and history

Inspect imported Feature Testing evidence or canonical ValidationRun / ValidationResult history. They are distinct stores and neither is independent proof of a gameplay PASS.

Imported test history Canonical validation history An empty or unconfigured history must not be interpreted as a verified successful run.

Readiness and authorization

Design-only is not runnable. MOG-09 has a separately restricted fixed local-operator observation path; INV-OBS-01 has no assigned runner, and staged domain designs must not be promoted through navigation. R8 advisory preflight, once released, remains NOT_AUTHORIZED with execution_enabled=false, even when declared prerequisites match.
