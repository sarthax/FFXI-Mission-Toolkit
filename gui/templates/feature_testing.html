Create the read-only database user (copy into your MariaDB console)

CREATE USER 'toolkit_ro'@'127.0.0.1' IDENTIFIED BY 'choose-a-password';
GRANT SELECT ON dspdb.char_inventory TO 'toolkit_ro'@'127.0.0.1';
GRANT SELECT ON dspdb.char_vars TO 'toolkit_ro'@'127.0.0.1';
GRANT SELECT (charid, keyitems) ON dspdb.chars TO 'toolkit_ro'@'127.0.0.1';


Replace dspdb with your database name. This login can only read inventory rows.
