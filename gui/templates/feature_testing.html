Test definition

The review endpoint verifies character allowlisting, a registered runner, and local preflight requirements. It returns a plan with expected observation steps; it does not issue execution authorization. Use the scenario detail to inspect assertions, then launch the reviewed plan through the local operator CLI documented in docs/workbench/LOCAL_TEST_SUPERVISOR_SETUP.md.

Operator-approved local execution

Only MOG-09 is available. Launch requires a separate operator token, a disposable allowlisted character and explicit approval. The token stays in this browser page's memory and is not stored.

No operator action submitted.
