Help & Overview

A local, read-only browser over indexed FFXI client/server reference data plus real captured gameplay sessions. Everything here reads from an already-built local database -- nothing here modifies a live server.

Tools

The things you work in day to day.

pagewhat it's for
Captures Upload, browse, and cross-reference real captured gameplay sessions. Each capture gets a timeline (events, battle actions, key items, dialogue, raw packets), position plots (2D top-down and 3D), and a search across every ingested capture at once. Supports .zip and .7z bundles, or dropping individual log files onto an existing capture.
Entity Lookup One canonical profile per NPC/mob id -- real position, model, drops, observed abilities, dialogue/events, level range, attack timing, and every capture it's appeared in, all cross- referenced from whichever real sources have data for it. Search by id, or by name in any style the client actually stored it in ("Lamia No.13", "Qiqirn_Treasure_Hunter", etc -- all normalize to the same match).
Wiki Compiler Pulls real item/NPC/mob references out of a wiki page and resolves them against the indexed data -- a reference aid, not a replacement for verifying against the real SQL/Lua.
Packet Decoder Decodes a raw captured packet into named, typed fields -- pick an opcode to see its full field reference, then decode real hex to populate real values into the same table. Also supports bulk-decoding a whole raw log file at once.

Research

Reference lookups for answering a specific question.

pagewhat it's for
Dialog Search Search or browse indexed dialogue text by keyword, id, or zone. Also has a zone drift report (comparing indexed dialogue against a zone's own live client data).
Browse by Zone List every entity/mob in a zone, a content-category tag, or both combined.
Zero-Position / Unregistered Finds entities with an unset position, or entities missing from a content type's registration table -- worth a look, not automatically a bug.
SQL Index Direct search over the indexed SQL tables (npc_list, mob_spawn_points, mob_groups, etc.) by id or name. Any row whose id is a real npcid (npc_list, mob_spawn_points, instance_entities) links straight through to its full Entity Lookup profile.
Events / CSIDs Per-zone list of every real cutscene/event id an entity can trigger. Generates itself automatically the first time you pick a zone you haven't looked at before.
Assault Missions Reference list of missions with their real zone/rank/prerequisites.
Key Items Search key items by name, with a readiness check against the scripting enum and any real capture evidence of that item being granted/removed.
Item Browser Our own item_basic/equipment/weapon/usable data next to the external retail reference and LandSandBoat, by normalized name -- shows id matches, id drift, and items either side is missing.
ID Drift The real fix for "wrong id" backport bugs: cross-checks LandSandBoat (what this content was ported from) against your Topaz server's own code/SQL across items, npcs, mob groups, mob skills, spells, abilities, weapon skills, traits, Blue Magic wiring, pets, status effects, and event/csid literals scraped straight out of both sides' npc scripts. Browse by category; zone-scoped categories have their own zone picker and a block-shift detector for "this whole zone's ids are off by a constant amount" bugs.

Tips

  • Pagination: every list that can exceed one page shows a real total count and a page-jump control (type a page number, click Go) -- a page never silently truncates results without telling you.
  • Search filters combine: where a page has more than one filter (e.g. Browse by Zone's zone + tag), each works alone or together -- you don't need to pick one first.
  • Cross-linking: ids, zones, and opcodes link to their own dedicated page wherever they appear (SQL Index → Entity Lookup, Wiki Compiler → Entity Lookup, ID Drift → Item Browser, a capture's NPC → its full entity profile → every other capture it appeared in), so you can follow a thread without re-searching.

Keeping data current

The homepage's "Data & Tools" table is where everything gets built or refreshed -- no command prompt needed. Each row is one real data source (Dialog text, your LSB server's own SQL, LandSandBoat cross-reference, your Topaz server's own SQL, BG Wiki, per-zone events, etc):

  • Rebuild re-indexes that source from whatever's already on disk (your Topaz checkout, the bundled LandSandBoat/ checkout, etc) -- click it after you edit your server's scripts, or whenever you want the freshest cross-reference.
  • Install appears instead when a source needs something that isn't downloaded yet (LandSandBoat, FFXI-DATS, xi-tinkerer-cli) -- one click fetches it from its real source, no manual download.
  • BG Wiki's Rebuild does an incremental sync (only pages that changed since last time, seconds to minutes) -- a full from-scratch crawl is a deliberate command-line-only step (scrape_bg_wiki.py --full) since it takes hours.
