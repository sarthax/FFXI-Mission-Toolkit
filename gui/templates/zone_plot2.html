Zone Editor help

Moving, rotating, snapping or dragging only changes the browser preview until you press Save to live DB (bottom bar). Every write is backed up first. The checked-in sql/*.sql files are separate: press Sync to SQL file once the live result is right.

Layout

  • Top bar: server / zone / instance, search, Undo / Redo, Frame, Clone. ☰ toggles the site menu, Focus (or Tab) hides both side panels.
  • Left panel: Entities (filterable match list), Layers (what to draw, colours, mesh, ranges/detection, navmesh) and Tools (Generator, Add, Backups).
  • 3D view toolbar: camera presets (Persp / Top / N / S / E / W), gizmo Move / Rotate, projection, Measure.
  • Right inspector: X / Y / Z / Rot for the selection with facing presets, step sizes, then collapsible Snap, Nudge and Model sections, animation, drops and history.
  • Bottom bar: dirty state, Save to live DB, Sync to SQL file, Revert, Copy SQL, comment and status.

Selection & camera

  • Click a dot or list row to select; double-click to select and frame. Ctrl/Cmd-click toggles multi-select. Shift-click sets the reachability anchor.
  • Left-drag orbits, right-drag pans (1:1 with the map under the cursor), wheel zooms toward the cursor. Zoom is proportional and scales with the zone size; Shift+wheel = fine, Ctrl+wheel = fast.
  • F frames the selection; Frame all fits the zone. Compass: FFXI rotation 0 = East, 64 = South, 128 = West, 192 = North (world +Z is north).

Generator (Tools)

  • Pick a pattern (Cluster, Row, Grid, Ring, Arc, Camp, Flank pair), set count / radius / spacing / heading / facing, choose the centre (selected entity, view centre or Add position) and press Preview to see ghost markers with their rotation.
  • Camp = one centre marker, a ring around it facing inward, and a looser outskirts ring facing out. Use the Place dropdown to place each role separately with different Add sources (e.g. fire, tents, crates).
  • Place via Add source creates one row per marker from the source picked in the Add tab (each write is backed up and undoable). Y can snap to the navmesh.
  • The older Mission descriptors previews existing mission mechanics.

Inspector (right panel)

  • X / Y / Z / Rot edit the preview; the dirty flag in the bottom bar lights up until you Save. Step / Rot step size the arrow keys, Nudge buttons and [ ] keys. Rot is the FFXI 0-255 byte; the line below it shows direction and compass degrees.
  • Facing presets (N…NW) set the rotation; ↶45° / 45°↷ / 180° turn relative to the current value.
  • Transform gizmo: Move / Rotate handles in the 3D view. Drag facing direction lets you drag in the view to aim; Click mesh to place moves the entity to the clicked mesh point with Y snapped.
  • Roam / detection text lists explicit roam/leash radii, family, detection senses and ranges (see below).
  • Snap & clipboard snaps to navmesh/mesh and copies or pastes positions. Nudge buttons & keyboard is the on-screen d-pad. Client model preview loads the model lazily.
  • Multi-select (Ctrl-click) shows the bulk panel for moving or rotating a group together.
  • Animation (NPC/door rows) and Drops (mobs) write to their own tables. A drop table is shared by the whole mob group, so a change affects every spawn of that group; the panel shows how many.
  • History lists backups of the selected entity. Delete… removes the row (and its instance links) after a backup; it never removes a now-empty mob group.
  • Bottom bar: Save writes the live DB, Sync writes the checked-in SQL file, Revert drops the preview, Copy SQL copies the statements; the comment is stored in the journal.

Add tab: what it does and does not do

  • Finding sources: search by name, or filter by source zone, mob family (partial) and sort by name / zone / level. Click a result to select it (highlighted), then click the map or drag the row onto the map to set the position.
  • Mob: inserts one mob_spawn_points row. If the source group comes from another zone, its mob_groups row is first cloned into this zone with groupid = highest in this zone + 1 (same pool, levels, drop table). If it is from this zone, the existing group is reused and shares its drops.
  • NPC: inserts a copy of the source npc_list row (look, flags, animation, etc.) with the new id and position.
  • Instance: if you pick an instance, a row is also added to instance_entities so a fixed instance loads it. With “None” it only joins the zone’s normal pool.
  • ID choice: the new id is the highest mob/npc id already used in this zone’s 4096-id block, plus 1 (shown as “Next id”). It does not fill gaps, does not look in the client DAT, and does not check other tables. The client only resolves mob/npc slots below 1024 (0x3FF); beyond that the tool warns you and the entity will not work in game.
  • Not done: it does not edit the zone Lua, IDs.lua, mob Lua scripts, mob_pools, family tables, spawn sets/respawn times or drop tables. A new NPC needs its scripts/zones/<zone>/npcs/<Name>.lua file or nothing happens when clicked, and a new mob with a new behaviour needs its Lua. Use Backups to undo.
  • Every add is backed up first and the SQL is shown in the message box and journal. Editing sql/*.sql by hand has no live effect until reimported; the live DB is written immediately.

Review tab

  • Missing scripts: lists NPCs with no Lua file under scripts/zones/<zone>/npcs; click one to select it.
  • Duplicates & collisions: finds rows within the chosen distance (and 3y in height) and draws red rings on them.
  • Spawn groups: per mob group: family, level range, spawn count, centre and spread. Click to select the whole group.
  • Camera bookmarks: named views saved per zone in this browser (not in the database).

Script & mods, bulk tools, templates, path measure

  • Script & mods (inspector): whether the entity's Lua file exists and every line that sets mods, flags or local vars. Add never writes these, so this shows what you still need to supply. Read-only.
  • Align / Spread / Mirror (multi-select): Align sets X, Y, Z or facing to the selection average / primary. Spread spaces rows evenly. Mirror flips about the selection centre and mirrors facing. Preview first, then Save.
  • Measure → path: with “path” ticked, the tool also routes across the navmesh (orange) and reports the walking distance, or says there is no route.
  • Generator templates: Save preview stores the layout as offsets from its centre (this browser only). Stamp re-creates it at the current centre; Place then adds rows from the Add source.

Quick finds

  • The zone box filters the zone list by partial name or number; the “by #” / “by name” control sorts it. If only one zone matches it is opened.
  • Colour by Mob family shows a legend of the families present in the zone with counts.

Backups

  • Snapshot the whole zone before large sessions; restore rolls back rows to an earlier state.

Ranges & detection (Layers)

  • Roam / leash circles show only when the server data defines them. Detection draws a sight cone (forward ±45°) and a hearing circle for the selected mob, or all mobs.
  • Which senses a mob has comes from SQL (mob_family_system.detects, mob_pools.aggro / true_detection). The default ranges (sight 15, sound 8 yalms) are engine constants, overridden by SIGHT_RANGE / SOUND_RANGE mob mods when set in SQL or literally in the mob's Lua. Other senses (low HP, magic, weapon skill, job ability, scent) have no radius and are listed as text.

Animation, model preview, NPC rows

  • NPC/door rows expose persistent animation / animationsub bytes (enum from LSB animation.yaml; subanimation meanings are model-dependent). FOURCC animation packets are transient and separate.
  • Client model preview (inspector) renders the model lazily and browses candidates read-only until you use the model-change workflow.
