Backport Package

Runs the full backport_package.py pipeline against one package folder under {{ packages_root }}: converts every .lua/.sql file, then runs the binding audit, Lua sanity check, and SQL id-collision check over the whole result, and writes one consolidated BACKPORT_REPORT.md next to the package. Run this again any time after editing a package's Lua or SQL to re-check for gaps -- missing bindings, flagged conversions, real SQL id collisions -- without leaving the browser. Still per-package, not a cross-package/cross-zone dependency crawl (see the script's own docstring for the honest boundary on what it does and doesn't automate).
