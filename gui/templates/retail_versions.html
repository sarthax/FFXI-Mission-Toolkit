Diagnostics and limitations

  • Downloader executable: {{ exe or 'not found (set RETAIL_FETCH_EXE or build tools/retail_fetch)' }}
  • Retail folder: {{ root }} (override with WORKBENCH_RETAIL_ROOT)
  • Network timeout per downloader call: {{ timeout }} s (maximum 600). The Rust client has a fixed 120 s socket timeout.
  • Manifest list is cached locally; tick refresh on the Manifest tab for one new network read.
  • Integrity check is the legacy FileSig (length, byte sum, MD5 prefix), not cryptographic. The patch server is contacted over unauthenticated TCP.
  • Open gap: the upstream manifest decoder has no output size cap.
  • Never run downloaded binaries. Keep the retail folder out of Git.
