Paths

  
Consumed by every SQL/Lua-grepping tool (Entity Lookup, SQL Index, Wiki
    Compiler, Zero-Position/Unregistered) and by zone geometry rendering (the path plot's
    coordinate-aligned overlay). Each module reads its root once at startup, so a change here
    takes effect the next time gui_server.py is restarted, not on the
    next request.

  

    

      

      
    

    

      

      
    

    

      

      
    

    

      

      
    

  


  
Live Client

  
Configure offline telemetry replay here rather than setting Windows environment variables. No running FFXI client is attached or modified. Saving these options requires restarting the toolkit before the recorded session is connected.

3D model viewer

  
Entity Lookup's "view 3D model" link opens
    xi-model-viewer
    at this URL with a real ?npc=<file_id> deep link -- run its dev
    server (npm run dev from vendor/xi-model-viewer/ui,
    plus py -3 scripts/serve.py for the file-read backend) and it opens
    that exact entity's model directly, no manual browsing.

Local LLM (Open WebUI / Ollama)

  
Used by the LLM Assistant page and any
    automated tool built on workbench.devtools.research.legacy_llm.client for draft-only offload work
    (summarizing, triage, first-pass suggestions) -- never for anything that writes an id/binding
    directly into a shipped package without a human/grep verification pass after it. Generate the
    API key yourself in Open WebUI's own UI (Settings → Account → API Keys) -- this
    toolkit has no way to create one for you.

  

    

      

      
    

    

      

      
    

    

      

      
    

  


  





Server


The port this toolkit listens on, plus controls for the server process itself.
  A port change (or any Paths change above) only takes effect on the next restart -- Restart
  does that for you without needing a terminal.



  

    

    
  

  

    
    

      
    

    

      
    

  





Database backups


A timestamped copy is taken automatically before any Rebuild click or CLI
  rebuild (at most once per 5 minutes). Use these if a rebuild ever goes wrong -- restoring
  replaces the live database with the chosen backup (a safety copy of the current state is taken
  first, so this is itself undoable) and restarts the toolkit.
