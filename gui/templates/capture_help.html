Capture Ingestion Help

Reference for capture/logging formats currently understood by Mission Toolkit. This page distinguishes formats that are ingested, files that are recognized but intentionally not duplicated, and known gaps that still need adapters or special handling.

Evidence stays source-specific. When the same packet or observation exists in multiple tools, Mission Toolkit keeps each source observation and provenance separately, then correlates equivalent evidence instead of silently collapsing it.

Raw packet convergence

Raw packet-producing tools feed the common capture_raw_packets evidence store while retaining their own source_format, native source identity, row/block provenance, and optional packet metadata. Equivalent packets may be correlated by opcode + direction + exact raw bytes; the original observations are not deleted or merged.

How unsupported files are handled

Files that do not match a supported parser are reported as unrecognized. Known formats found in unexpected paths are content-sniffed and reported as likely known formats so path/layout regressions can be distinguished from genuinely new logger families. Source manifests, hashes, ingestion lineage, and row locators preserve what was actually consumed.

Current priority gaps

  1. Decode preserved PCAP/PCAPNG traffic by connection role: zone/map vs lobby/login vs world/search, without mixing protocol namespaces.
  2. Decide whether PacketDB ZONES and PACKET_DEFINITION should be retained as historical reference evidence.
  3. Evaluate a live PacketBridge adapter if live streaming adds value beyond file/network capture.
  4. Continue searching historical Windower/Ashita/Captain/community repositories and old capture archives for formats not represented here.
  5. Add derived interchange importers such as PacketViewer-derived NDJSON only when real archived evidence requires them.

This page documents current parser behavior, not every logger ever written. When a new sample appears, verify its real schema/output before declaring compatibility.
