Direct Live Bridge

Local, read-only Ashita telemetry. No recording files or game writes.

Start receiver is one step: it reuses saved credentials and port (so restarts need no reconfiguration) and writes the settings file into your Ashita addon folder (set the folder under "Install Ashita addon" once; it is remembered). Regenerate credentials revokes the old ones. Existing credentials were revoked. Settings are private.

Changing this option writes an updated private settings file on Start receiver. Reload the Ashita addon and restart direct telemetry to apply it. Recorded JSONL exports are unaffected.

Start receiver, then configure and download settings for your Ashita addon.

  1. Click Start receiver.
  2. If the Ashita folder is not set yet, enter it below once (or download the settings file manually).
  3. Reload the addon only if the settings changed, then run /wblive live start ashita-a in game.

Install native plugin (warp / position)

 
Copies the prebuilt workbench_native_probe.dll into the Ashita folder entered below (an existing DLL is backed up) and creates settings.ini only if missing. Unload the plugin in game first if it is loaded.

 
 
 
A stock install has no config/workbench_native/settings.ini. The plugin ignores all Toolkit commands until it contains allow_file_commands=1, and ignores GM chat until it contains allow_chat_commands=1. The installer writes these lines from the boxes above (only when the file is missing); edit the file by hand to change them later, then reload the plugin.
